# Changelog

## 1.1.0

### Added

- Added support for native Obsidian PDF export settings in the preview.
- Added preview support for **Include file name as title**.
- Added preview support for **Landscape** orientation.
- Added preview support for **Margin** settings.
- Preview now updates when native PDF export settings are changed.

### Improved

- Improved consistency between the PDF preview and the native Obsidian PDF export settings.

## 1.0.0

### Added

- Custom text size for PDF export.
- A4 PDF preview.
- Page-by-page navigation.
- Support for Obsidian themes.
- Support for Style Settings.
- Support for CSS snippets.
