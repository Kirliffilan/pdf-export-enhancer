# Changelog

## 2.0.0

### Added

- Added page numbers with configurable visibility and position.
- Added an option to skip the first page number.
- Added H1 and H2 page break controls.
- Added monochrome PDF output.
- Added custom page margins for top, bottom, left, and right sides.
- Added configurable line spacing.
- Added custom file name as title control.
- Added landscape orientation control.
- Added automatic preview pagination based on A4 page dimensions.

### Improved

- Redesigned the PDF export dialog with a dedicated settings panel and larger preview area.
- Centered the settings and preview block inside the export window.
- Reduced settings control sizes and improved space allocation for long setting names.
- Added a dedicated **Text** section for the font size setting.
- Improved page navigation and preview updates when PDF settings change.
- Improved the transition between preview pages to avoid visible flickering.
- Improved modal initialization to avoid showing the native dialog before the enhanced UI is ready.
- Kept the preview aligned with the native Obsidian PDF export settings.

## 1.1.0

### Added

- Added support for native Obsidian PDF export settings in the preview.
- Added preview support for **Include file name as title**.
- Added preview support for **Landscape** orientation.
- Added preview support for **Margin** settings.
- Preview now updates when native PDF export settings are changed.

### Improved

- Improved consistency between the PDF preview and the native Obsidian PDF export settings.

## 1.0.0

### Added

- Custom text size for PDF export.
- A4 PDF preview.
- Page-by-page navigation.
- Support for Obsidian themes.
- Support for Style Settings.
- Support for CSS snippets.
